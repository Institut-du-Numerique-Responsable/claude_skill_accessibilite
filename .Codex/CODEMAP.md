# Code map

- `README.md` : documentation principale du projet, installation, usage et références.
- `CONTRIBUTING.md` : règles de contribution et de revue.
- `CITATION.cff` : attribution officielle du projet à l’INR et à Guillaume Gallon.
- `skills/rgaa-declaration-accessibilite/SKILL.md` : déclencheurs, données requises, règles et déroulement du skill.
- `skills/rgaa-declaration-accessibilite/template.md` : modèle Markdown de déclaration RGAA avec champs variables.
- `docs/index.html` : page publique GitHub Pages, styles et métadonnées inclus.
- `docs/llms.txt` : résumé et liens destinés aux assistants et moteurs IA.
- `docs/robots.txt` : directives d’exploration et lien vers le sitemap.
- `docs/sitemap.xml` : URL canonique de la page publique.
- `tests/test_project.py` : contrôles déterministes du modèle, du skill et des fichiers publics.
- `.github/workflows/quality.yml` : exécution des contrôles à chaque push et pull request.
