# Contribuer

Toute contribution passe par une **pull request** — pas de push direct sur
`main`.

## Process

1. Forker le dépôt et créer une branche descriptive
   (`fix/...`, `feat/...`, `docs/...`).
2. Faire les modifications, en gardant intact le texte légal du modèle
   officiel (engagement article 47, procédure de recours Défenseur des
   droits) sauf si vous corrigez une erreur avérée par rapport au modèle
   source.
3. Ouvrir une pull request décrivant le changement et sa motivation.
4. Une relecture est nécessaire avant fusion.

## Signaler un problème

Utiliser les [issues GitHub](../../issues) pour signaler une non-conformité
avec le modèle officiel, une erreur dans `template.md`, ou une amélioration
du `SKILL.md`.
