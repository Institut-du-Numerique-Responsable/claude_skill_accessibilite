Déclaration d'accessibilité RGAA — Skill Claude

Ce skill pour Claude Code génère une déclaration d'accessibilité conforme au modèle officiel du design system de l'État, au titre de l'article 47 de la loi n°2005-102 et du RGAA (Référentiel Général d'Amélioration de l'Accessibilité).

Publié par l'Institut du Numérique Responsable.

Installation

cp -r skills/rgaa-declaration-accessibilite ~/.claude/skills/

Fonctionnement

  • Collecte les données d'audit RGAA (taux de conformité, non-conformités, dérogations).
  • Génère la déclaration au format Markdown, texte légal inchangé.
  • Signale les informations manquantes plutôt que d'inventer des résultats.
