RGAA 4.1.2 Secteur public Accessibilité MIT

Créez une déclaration d’accessibilité RGAA conforme

Toute administration publique doit publier une déclaration d’accessibilité conforme au modèle officiel de l’État. Rédiger ce document manuellement est source d’erreurs : sections oubliées, taux de conformité incohérents, mentions légales reformulées.

Ce skill pour Claude Code automatise la génération à partir de vos résultats d’audit RGAA 4.1.2, en suivant strictement le modèle officiel du design system de l’État. Les mentions légales (article 47, recours Défenseur des droits) restent intactes, mot pour mot.

Publié par l’Institut du Numérique Responsable. Code source.

Parcours : de l’audit à la déclaration

1
Audit RGAA
Réalisez un audit complet avec un outil qualifié (Tanaguru, AccessiNum) ou un auditeur certifié. Notez les non-conformités, les dérogations et les taux de conformité.
2
Données vérifiées
Le skill collecte vos données d’audit et valide leur cohérence : niveau de conformité, pourcentage de critères respectés, taux moyen, justifications des dérogations.
3
Déclaration prête à publier
Génération automatique d’une déclaration Markdown conforme, prête à être publiée sur votre site. Tous les liens officiels (Défenseur des droits, modèle gouv.fr) sont inclus.

Publics prioritaires

  • Responsables accessibilité dans les administrations publiques
  • Développeurs et équipes techniques du secteur public
  • Chefs de projet en charge de la conformité numérique

Ce que le skill fait

  • Collecte les données d’audit RGAA 4.1.2 (taux de conformité, non-conformités, dérogations avec justification et alternative accessible)
  • Valide la cohérence entre le niveau de conformité et les taux déclarés
  • Génère une déclaration Markdown conforme au modèle officiel
  • Exige les liens vers le schéma pluriannuel et le plan d’action (quand ils existent)
  • Signale explicitement les informations manquantes

Ce qu’il ne fait pas

  • ❌ Réaliser l’audit RGAA à votre place
  • ❌ Corriger le code de votre site
  • ❌ Inventer des résultats d’audit
  • ❌ Reformuler le texte légal officiel

Exemple de sortie

## État de conformité

www.exemple.gouv.fr est **partiellement conforme** 
avec le RGAA 4.1.2.

**Résultats des tests** :
- Pourcentage de critères respectés : 72%
- Taux moyen de conformité : 85%

Installation

Copiez le dossier du skill dans votre répertoire de skills Claude :

cp -r skills/rgaa-declaration-accessibilite ~/.claude/skills/

Ou placez-le dans .claude/skills/ à la racine de votre projet pour l’activer uniquement sur ce projet.

Données attendues

  • Organisation et service concerné
  • URL du site ou de l’application
  • Date et auditeur de l’audit RGAA 4.1.2
  • Niveau de conformité (non/partiellement/totalement conforme)
  • Pourcentage de critères respectés et taux moyen de conformité
  • Liste des non-conformités avec échéances
  • Dérogations avec justification et alternative accessible
  • Technologies, environnements de test, outils utilisés
  • Liens vers le schéma pluriannuel et le plan d’action
  • Coordonnées du responsable accessibilité

Limites

  • Le skill ne réalise pas l’audit : un audit pré-existant est requis
  • Les résultats générés dépendent de la qualité des données fournies
  • Le skill ne vérifie pas l’exactitude des audits, seulement leur cohérence formelle
